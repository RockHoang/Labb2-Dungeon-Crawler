# Labb 2 Dungeon-Crawler
Spelaren går omkring i en dungeon fylled med ormar och råttor. Spelaren rör sig med hjälp av pill-tangenterna. Spelaren kan slåss med ormar och råttor.
Samt råttor och ormar kan slåss med spelare. Strider görs med tärningskast. 

När du kompilerar proagramet så kanske du behöver placera Level1.txt i den map din bin fil skapas.
